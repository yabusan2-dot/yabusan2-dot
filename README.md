## 🚀 開発プロジェクト ＆ 成果物一覧

### 1. 🎵 Web Audio API 音楽クリエイターツール（公開中）
* **リポジトリ**: [`my-music-tools`](https://github.com/yabusan2-dot/my-music-tools)
* **技術スタック**: JavaScript (Vanilla JS), Web Audio API, Node.js, OpenAI API
* **概要**: 外部の音源ファイル（Wav/MP3等）に依存せず、CanvasとWeb Audio APIのコード制御のみで効果音やBGMを動的生成する実験的ツール群。サンプルフレーズの生成ロジックにOpenAI APIを組み込むなど、AI連携の可能性を模索した作品です。
* **内包ツール**: シーケンサー、ミキサー、リズムマシーン、SEジェネレーター

### 2. 🥏 WebSocket エアーホッケー（リアルタイム対戦サーバー） 【近日公開】
* **技術スタック**: Node.js (標準モジュールのみ), WebSocket, HTML5 Canvas
* **特長**: 外部ライブラリ（socket.io等）に頼らず、RFC 6455準拠のバイナリフレーム解析・マスク解除を自前で実装。通信遅延（レイテンシ）を徹底検証し、すべての物理演算（衝突判定・速度計算）をサーバー側で一元管理する「サーバーサイド・オーソリティ方式」を採用したガチガチの同期型対戦エンジン。

### 3. ⚾ 2.5D スマホ連動型バッティングシミュレーター 【近日公開】
* **技術スタック**: JavaScript, WebSocket, Android Java (Sensor API)
* **特長**: スマホの3軸加速度・傾き（Roll角）をリアルタイムにバットの軌道行列へコンバートするマルチデバイス連携。3Dエンジンを使わず、投球時の「斜め30度視点」とインパクト時の「真上俯瞰ビュー」を直交反転させる2.5次元カメラワークをCSSとCanvasのみで軽量実装。サードやレフトなど扇形フィールドの野手守備半径（r）と打球の仮想高さによる3次元コリジョン（当たり判定）を数理実装。

### 4. 📱 Android Java 暗号通信 ＆ センサー連動ゲーム 【近日公開】
* **技術スタック**: Java, Android SDK, BigInteger (多倍長整数演算)
* **特長**: RSA暗号や楕円曲線暗号（ECC）の数理理論を3日間で解読し、スクラッチで暗号化・復号モジュールを実装。JavaのBigInteger仕様に伴う先頭符号ビット（0x00）の除去や、ネットワーク転送時の128バイト固定長ブロックバッファの厳格なパディング制御を自力で実装し、パケット崩壊を防ぐ堅牢性を担保。また、端末の物理センサーと連動した「玉転がし迷路脱出ゲーム」も内包。

## 📖 記述解説ドキュメント（技術Wiki） 【近日公開】

単なるソースコードの公開にとどまらず、開発・検証のプロセスで得られた数理分析や、初学者向けのメンター資料を独立したナレッジベースとして公開予定です。

* **『AI時代におけるロジックの重要性とLLMの限界検証』**
  SPIや基本情報の数理問題を題材に、主要4大AI（Google/Copilot/ChatGPT/Claude）に同一問題を投げたベンチマーク調査。複雑な境界条件においてAIが「局所解（ローカルミニマム）」に陥って誤答を吐き出す特性を、数値解析（ニュートン・ラフソン法等）のアナロジーで解説。
* **『1バイトの処理から数理宇宙へ：ビットカウントアルゴリズムの探求』**
  ハミング重量（立っている1の数を数える）の6つのアプローチ（力まかせ、置換テーブル、カーニハン流、HAKMEMの魔術、並列加算、popcnt）の物理ベンチマーク検証。データが1024ビットに巨大化した際の \(O(\log N)\) スケール戦略の提示、および0と1の羅列から距離空間（ハミング距離）を経て生成AIの本質であるベクトル空間の近傍系（トポロジー）へと繋がる数学的考察。
